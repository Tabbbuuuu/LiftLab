# LiftLab
Holographic 3D muscle map for tracking training volume, recovery, strength plateaus, dynamic rest timer, barbell movement tracker. 


Current sub-project:  Muscle map 
      --- MuscleMap is a workout analytics app built around an interactive 3D anatomy model. 
        - Click a muscle group to zoom in and see weekly volume, recovery status, estimated 1RM trends, and plateau alerts based on your own training history. 
        - Built with React, TypeScript, React Three Fibre, FastAPI, and PostgreSQL.

Later sub-projects: 
        - RepPrint (camera-based rep and movement analysis with MediaPipe)
        - RestIQ (personalised rest recommendations from your own data).
